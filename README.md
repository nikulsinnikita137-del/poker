# Техасский холдем — механика игры

Учебный проект (ВГУ, ФКН, Java). Вариант 3: покер, этап 2 — механика.

## Принципы
- Механика не печатает в консоль: она возвращает состояние и события.
- Все случайные величины берутся из одного `Random` с заданным зерном.

## Модель
| Пакет | Что внутри |
|---|---|
| `card` | `Suit`, `Rank`, `Card`, `Deck` (тасуется переданным `Random`) |
| `eval` | `HandCategory` (порядок старшинства), `HandValue` (сравнение), `HandEvaluator` (лучшие 5 из 7) |
| `pot` | `SidePotCalculator` — основной и побочные банки, `Pot.split` — деление при ничьей |
| `game` | `Player`, `Blinds`, `Position`, `Table` (кнопка, блайнды, раздача, ходы), `BettingRound` (правила ставок) |
| `action` | `Action` (fold, check, call, raise, all-in), `IllegalActionException` |
| `phase` | `HandPhase` и фазы `PreFlopPhase`, `FlopPhase`, `TurnPhase`, `RiverPhase`, `ShowdownPhase` — паттерн «Состояние» |
| `event` | `GameEvent` — события партии; механика их возвращает, а не печатает |

## Как идёт раздача
1. `table.startHand()` — кнопка, блайнды, карманные карты, начало префлопа.
2. `table.currentPlayer()` — чей ход; `table.act(action)` — сделать ход. Недопустимый ход — `IllegalActionException`, состояние не меняется.
3. Когда круг торговли закончен, стол сам открывает карты и начинает следующий круг (`HandPhase.next()`).
   Если все остальные сбросили карты или торговаться не с кем (все на всё), раздача идёт до вскрытия.

Правила повышения: «raise to» не меньше текущей ставки плюс размер последнего повышения (в начале круга — большой блайнд).
All-in меньше полного повышения не открывает торговлю заново для тех, кто уже ходил.
