# Техасский холдем — механика игры

Учебный проект (ВГУ, ФКН, Java). Вариант 3: покер, этап 2 — механика.

## Принципы
- Механика не печатает в консоль: она возвращает состояние и события.
- Все случайные величины берутся из одного `Random` с заданным зерном.

## Запуск
```
mvn test
```
