# Техасский холдем — механика игры

Учебный проект (ВГУ, ФКН, Java). Вариант 3: покер, этап 2 — механика.

## Принципы
- Механика не печатает в консоль: она возвращает состояние и события.
- Все случайные величины берутся из одного `Random` с заданным зерном.

## Модель
| Пакет | Что внутри |
|---|---|
| `card` | `Suit`, `Rank`, `Card`, `Deck` (тасуется переданным `Random`) |
| `eval` | `HandCategory` (порядок старшинства), `HandValue` (сравнение), `HandEvaluator` (лучшие 5 из 7) |
| `pot` | `SidePotCalculator` — основной и побочные банки, `Pot.split` — деление при ничьей |
| `game` | `Player`, `Blinds`, `Position`, `Table` (кнопка, блайнды, раздача, ходы), `BettingRound` (правила ставок), `HandResolver` (вскрытие и выдача банков) |
| `action` | `Action` (fold, check, call, raise, all-in), `IllegalActionException` |
| `phase` | `HandPhase` и фазы `PreFlopPhase`, `FlopPhase`, `TurnPhase`, `RiverPhase`, `ShowdownPhase` — паттерн «Состояние» |
| `bot` | `Bot`, `CallingStationBot`, `RandomBot` (общий `Random` с колодой) |
| `sim` | `GameRunner` — прогон раздач, ходы ботов, события слушателю |
| `console` | `ConsoleApp` (точка входа), `EventFormatter` (журнал по-русски), `HumanBot` (ввод человека) |
| `event` | `GameEvent` — события партии; механика их возвращает, а не печатает |

## Как идёт раздача
1. `table.startHand()` — кнопка, блайнды, карманные карты, начало префлопа.
2. `table.currentPlayer()` — чей ход; `table.act(action)` — сделать ход. Недопустимый ход — `IllegalActionException`, состояние не меняется.
3. Когда круг торговли закончен, стол сам открывает карты и начинает следующий круг (`HandPhase.next()`).
   Если все остальные сбросили карты или торговаться не с кем (все на всё), раздача идёт до вскрытия.
4. На вскрытии `HandResolver` делит вклады на основной и побочные банки (`SidePotCalculator`), для каждого банка
   находит сильнейшую руку из семи карт (`HandEvaluator`) и выдаёт выигрыш. При равенстве банк делится,
   нечётная фишка достаётся первому победителю слева от кнопки. Неуравненная часть ставки возвращается владельцу.
   Если остался один игрок, карты не вскрываются. Новую раздачу можно начать только после окончания текущей.

Правила повышения: «raise to» не меньше текущей ставки плюс размер последнего повышения (в начале круга — большой блайнд).
All-in меньше полного повышения не открывает торговлю заново для тех, кто уже ходил.

## Запуск
Тесты:
```
mvn test
```
Консольное приложение (класс `ru.vsu.poker.console.ConsoleApp`). В IntelliJ IDEA: запустить `main`, ключи задаются в
**Run → Edit Configurations → Program arguments**. Из консоли после `mvn compile`:
```
java -cp target/classes ru.vsu.poker.console.ConsoleApp --seed 42 --hands 5
java -cp target/classes ru.vsu.poker.console.ConsoleApp --human --players 3
```
| Ключ | Что делает | По умолчанию |
|---|---|---|
| `--seed N` | зерно: одно зерно — одна и та же партия | 42 |
| `--hands N` | сколько раздач сыграть | 5 |
| `--players N` | число игроков, 2–9 | 4 |
| `--stack N` | стартовый стек | 1000 |
| `--human` | вы играете за место 0 | выключено |

Команды человека: `fold`, `check`/`call` (`c`), `raise N` (`r N`), `allin` (`a`), `help`.
